**Documentación inicial de un producto digital**

- Respondé las preguntas sección por sección (visión, usuarios, valor, métricas, alcance, requisitos, historias, no funcionales, datos, riesgos y plan). Marcá lo que no aplica y lo que queda como duda.
- Dibujá los flujos principales (inicio, pasos, pantallas, decisiones) y bocetá pantallas a mano alzada.
- En "Documento" ves qué falta para que un analista pueda arrancar, y exportás a Markdown (con los flujos en Mermaid), HTML, PDF o JSON editable.

Es un solo `index.html`, sin instalar nada. Tu trabajo se guarda en este navegador y podés tener varios proyectos.
